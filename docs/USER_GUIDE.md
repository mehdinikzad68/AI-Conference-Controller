## 🎯 معرفی سیستم

**AI-Symp-Controller** یک سیستم یکپارچه برای مدیریت همایش‌های علمی است که شامل:

### ویژگی‌های کلیدی:
- ⏱️ **تایمر هوشمند** با قابلیت کنترل دقیق زمان سخنرانی‌ها
- 📊 **مدیریت برنامه زمانی** با validation و overlap detection
- 🎥 **تحلیل هوشمند چهره** برای سنجش توجه مخاطبان
- 📺 **مدیریت نمایشگرهای چندگانه** برای نمایش اطلاعات
- 🎬 **پخش رسانه** (تصویر، ویدئو، PDF)
- 🏢 **پشتیبانی از همایش چند سالنه** (Multi-Track)
- ↶ **Undo/Redo** برای بازگشت تغییرات
- 🔐 **احراز هویت و سطوح دسترسی**

## 💻 نصب و راه‌اندازی

### پیش‌نیازها:
- Python 3.10 یا بالاتر
- Windows 10/11, Linux, یا macOS
- 4 GB RAM (حداقل)
- کارت گرافیک با پشتیبانی از OpenGL

### مراحل نصب:

#### 1. دانلود و استخراج:
```bash
cd AI-Symp-Controller
```

#### 2. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

#### 3. اجرای برنامه:
```bash
python main.py
```

### اولین راه‌اندازی:
در اولین اجرا، برنامه از شما می‌پرسد:
- 📁 انتخاب پوشه پروژه
- 🎤 تنظیمات دوربین (برای Face AI)
- 📺 انتخاب نمایشگرها

```

رمز عبور: admin123
```

⚠️ **هشدار**: بلافاصله پس از ورود، رمز عبور را تغییر دهید!

1. منوی **Settings** → **Change Password**

## 🎛️ داشبورد اپراتور

پس از ورود، داشبورد اصلی نمایش داده می‌شود:

### بخش‌های داشبورد:

#### 1️⃣ **Module Status** (بالا، چپ):
نمایش وضعیت هر ماژول:
- 🟢 **سبز**: فعال و در حال کار
- 🟠 **نارنجی**: هشدار (نیاز به توجه)
- 🔴 **قرمز**: خطا (نیاز به رفع مشکل)
- ⚪ **خاکستری**: غیرفعال

**کلیک روی هر ماژول** → باز شدن پنجره آن ماژول

#### 2️⃣ **Active Sessions** (مرکز):
لیست تایمرها و session‌های در حال اجرا:
```
⏱️  Main Timer: 15:30
🎤 Dr. Smith - AI in Healthcare (Hall A)
🎤 Prof. Lee - Robotics (Hall B)
```

#### 3️⃣ **Live AI Metrics** (مرکز، پایین):
- **Audience Attention**: میزان توجه مخاطبان (%)
- **Faces Detected**: تعداد چهره‌های شناسایی شده
- **Presenter Status**: وضعیت سخنران

#### 4️⃣ **Recent Alerts** (راست):
هشدارهای اخیر:
```
[14:23] ⚠️ Timer ending in 2 minutes
[14:20] ⚠️ Camera reconnected (3 attempts)
[14:15] ⚠️ Display 2 disconnected
```

#### 5️⃣ **Event Log** (راست، پایین):
لاگ تمام رویدادها:
```
[14:25] Timer started (30:00)
[14:24] Media loaded: presentation.pdf
[14:23] Session started: Dr. Smith
```

#### 6️⃣ **Quick Actions** (پایین):
دکمه‌های دسترسی سریع:
- 🕐 **New Timer**: ساخت تایمر جدید
- 📁 **Load Media**: بارگذاری رسانه
- 🎥 **Start Face AI**: شروع تحلیل چهره
- 🖥️ **Validate Displays**: بررسی نمایشگرها
- 📊 **Generate Report**: گزارش‌گیری
- ⚠️ **Emergency Stop**: توقف اضطراری (قرمز)

#### 7️⃣ **System Resources** (فوتر):
- CPU، RAM، Uptime

## 📅 مدیریت برنامه زمانی (Agenda)

### ساخت Agenda جدید:

#### 1. باز کردن پنجره:
**Modules** → **Symposium Manager**

#### 2. تنظیمات اولیه:
```
عنوان همایش: AI Conference 2025
تاریخ: 2025-11-04
مکان: Convention Center
```

#### 3. اضافه کردن Session:
کلیک **Add Session**:

```
Session ID: session_01
Start Time: 09:00
Speaker Name: Dr. John Smith
Title: Introduction to AI
Duration: 60 minutes
Organization: MIT
Email: john.smith@mit.edu
Bio: Professor of Computer Science...
```

**Save** → Session به لیست اضافه می‌شود

### ویژگی‌های خودکار:

#### ✅ **Time Validation**:
برنامه خودکار بررسی می‌کند:
- آیا format زمان صحیح است؟ (HH:MM)
- آیا duration معتبر است؟ (1-1440 دقیقه)
- آیا با session دیگری تداخل دارد؟

**مثال خطا**:
```
❌ Invalid time: 25:99
❌ Duration too short: 0 minutes
❌ Schedule Conflict!
   Session 'session_02' (09:30-10:30)
   Conflicts with 'session_01' (09:00-10:00)
```

#### ✅ **Input Sanitization**:
برنامه خودکار:
- Null bytes را حذف می‌کند
- Strings خیلی طولانی را کوتاه می‌کند
- Email را اعتبارسنجی می‌کند
- Unicode (فارسی، عربی، چینی) را پشتیبانی می‌کند

#### ✅ **Overlap Detection**:
اگر دو session همپوشانی داشته باشند، هشدار نمایش داده می‌شود.

### ذخیره و بارگذاری:

**Save Agenda**: `File → Save Agenda`
- فایل JSON ذخیره می‌شود
- Backup اتوماتیک ساخته می‌شود

**Load Agenda**: `File → Load Agenda`
- انتخاب فایل JSON
- Validation خودکار

## ⏱️ راه‌اندازی تایمر

### تایمر ساده:

1. **Modules** → **Timer**
2. تنظیم زمان:
   ```
   Hours: 00
   Minutes: 30
   Seconds: 00
   ```
3. کلیک **Start**

### تایمر پیشرفته:

#### قابلیت‌ها:
- ⏸️ **Pause/Resume**
- ⏹️ **Stop**
- ➕ **Add Time**: افزودن زمان در حین اجرا
- ➖ **Subtract Time**: کم کردن زمان
- 🔔 **Alerts**: هشدار در 5 دقیقه، 2 دقیقه، 30 ثانیه

### تایمر هوشمند (AI Timer):
اگر Face AI فعال باشد:
- تایمر خودکار سرعت را تنظیم می‌کند
- اگر مخاطبان خسته شوند → کوتاه‌تر می‌کند
- اگر توجه بالا باشد → طولانی‌تر می‌کند

## 🎬 مدیریت رسانه (Media)

### بارگذاری رسانه:

1. **Modules** → **Media Manager**
2. کلیک **Add Media**
3. انتخاب فایل:
   - 🖼️ تصویر: JPG, PNG, BMP

- دوبار کلیک → نمایش Fullscreen
- کلید `ESC` → خروج از Fullscreen

### پخش ویدئو:
- ⏯️ Play/Pause
- ⏹️ Stop
- 🔊 Volume
- ⏩ Seek

## 🎥 هوش مصنوعی چهره (Face AI)

### راه‌اندازی:

1. **Modules** → **Face AI**
2. انتخاب دوربین
3. کلیک **Start Analysis**

### اطلاعات نمایش داده شده:

#### 1. **Faces Detected**: تعداد چهره‌ها

#### 2. **Emotions**:
```
😊 Happy: 45%
😐 Neutral: 30%
😟 Sad: 10%
😠 Angry: 5%
```

#### 3. **Attention Level**:
- 🟢 High (80-100%): مخاطبان متمرکز
- 🟡 Medium (50-79%): توجه متوسط
- 🔴 Low (0-49%): کم‌توجهی

#### 4. **Head Pose**:
- تشخیص جهت نگاه
- آیا به سخنران نگاه می‌کنند؟

### توصیه‌های خودکار:
```
💡 Suggestion: Audience attention is low.
   Consider taking a break or changing topic.
```

### خاموش کردن:
کلیک **Stop Analysis**

## 🏢 همایش چند سالنه (Multi-Track)

برای همایش‌هایی با چند سالن موازی:

### 1. فعال‌سازی:
**Settings** → **Enable Multi-Track Mode**

### 2. تعریف سالن‌ها:
```
Hall A: 200 نفر
Hall B: 150 نفر
Hall C: 100 نفر
```

### 3. اضافه کردن Session‌های موازی:
```
Session 1:
  Time: 09:00
  Room: Hall A
  Speaker: Dr. Smith

Session 2:
  Time: 09:00  ← همان زمان!
  Room: Hall B  ← سالن دیگر
  Speaker: Prof. Lee
```

**✅ تداخلی نیست** چون سالن‌ها متفاوتند

### 4. نمایش:
- هر سالن تایمر مستقل دارد
- هر سالن نمایشگر مجزا دارد
- مدیریت متمرکز از داشبورد

## ↶ Undo/Redo

### استفاده:

- **Ctrl+Z**: Undo (بازگشت آخرین تغییر)
- **Ctrl+Y**: Redo (انجام مجدد)

## 🛠️ عیب‌یابی

### مشکل: دوربین کار نمی‌کند

**راه‌حل**:
1. بررسی اتصال دوربین
2. **Modules** → **Face AI** → **Camera Test**
3. اگر دوربین disconnect شد:
   - برنامه خودکار reconnect می‌کند
   - تا 10 بار تلاش می‌کند
   - هشدار نمایش داده می‌شود

### مشکل: Config file خراب شده

**راه‌حل**:
برنامه خودکار از backup استفاده می‌کند:
```
configs/
  config.json        ← فعلی
  config.json.bak    ← backup
  config.json.bak.1  ← backup قدیمی‌تر
```

### مشکل: برنامه کند شده

**راه‌حل**:
1. بستن ماژول‌های غیرضروری
2. **Settings** → **Clear Cache**
3. Restart برنامه

### مشکل: نمایشگر disconnect شده

**راه‌حل**:
1. **Display Manager** → **Validate Displays**
2. بررسی اتصال فیزیکی
3. Refresh
