# 🎛️ راهنمای کنترل‌های Unified Dashboard

## 📋 خلاصه

در Unified Dashboard حالا می‌توانید:
- ✅ هر ماژول را **جداگانه** فعال/غیرفعال کنید
- ✅ کنترل‌های **پیشرفته** برای هر ماژول داشته باشید
- ✅ وضعیت هر ماژول را **زنده** مشاهده کنید

---

## 🎯 Tab: Control (کنترل ماژول‌ها)

### 1. Timer Module (ماژول تایمر)

**کنترل‌ها:**
- **Start**: شروع تایمر
- **Stop**: توقف تایمر
- **Pause**: توقف موقت
- **Resume**: ادامه از توقف

**وضعیت:**
- **Active** (سبز): در حال کار
- **Inactive** (قرمز): متوقف شده

**نحوه استفاده:**
```
1. کلیک: Start → تایمر شروع می‌شود
2. در صورت نیاز: Pause → توقف موقت
3. Resume → ادامه
4. Stop → توقف کامل
```

---

### 2. Face AI Module (تحلیل چهره)

**کنترل‌ها:**
- **Start**: شروع تحلیل چهره
- **Stop**: توقف تحلیل

**تنظیمات:**
- **FPS**: تعداد فریم در ثانیه (5-30)
  - پیش‌فرض: 15 fps
  - بیشتر = دقیق‌تر اما سنگین‌تر
  - کمتر = سریع‌تر اما کمتر دقیق

**نحوه استفاده:**
```
1. Camera را انتخاب کنید (Audience Camera)
2. FPS را تنظیم کنید (مثلاً 15)
3. کلیک: Start
4. Face AI شروع به تحلیل می‌کند
```

---

### 3. AI Timing Module (هوش مصنوعی زمان‌بندی)

**کنترل‌ها:**
- **Start**: شروع AI Timing
- **Stop**: توقف AI Timing

**تنظیمات:**
- **Voice Detection**: فعال/غیرفعال کردن تشخیص صدا
  - ✅ فعال: از میکروفون استفاده می‌کند
  - ❌ غیرفعال: فقط از دوربین استفاده می‌کند

**نحوه استفاده:**
```
1. Presenter Camera را انتخاب کنید
2. Audience Camera را انتخاب کنید
3. Microphone را انتخاب کنید
4. Voice Detection را فعال/غیرفعال کنید
5. کلیک: Start
```

---

### 4. Content Automation Module (اتوماسیون محتوا)

**کنترل‌ها:**
- **Start**: شروع اتوماسیون محتوا
- **Stop**: توقف اتوماسیون محتوا

**نحوه استفاده:**
```
1. کلیک: Start
2. Content Automation شروع می‌شود
3. می‌توانید از Content Automation Dashboard استفاده کنید
4. کلیک: Stop → توقف کامل
```

---

### 5. Display Module (مدیریت نمایشگر)

**کنترل‌ها:**
- **Refresh**: به‌روزرسانی نمایشگرها
- **Stop**: توقف استفاده از نمایشگر

**نحوه استفاده:**
```
1. کلیک: Refresh → نمایشگرها شناسایی می‌شوند
2. در صورت نیاز: Stop
```

---

### 6. Media Module (مدیریت رسانه)

**کنترل‌ها:**
- **Start**: شروع Media Player
- **Stop**: توقف Media Player
- **Pause**: توقف موقت پخش
- **Resume**: ادامه پخش

**نحوه استفاده:**
```
1. کلیک: Start
2. فایل را load کنید
3. Play کنید
4. در صورت نیاز: Pause/Resume
5. Stop → توقف کامل
```

## 🎮 مثال‌های کاربردی

### مثال 1: شروع فقط Face AI

```
1. به Tab "Control" بروید
2. در بخش "Face AI":
   - Camera را انتخاب کنید
   - FPS را تنظیم کنید (15)
   - کلیک: Start
3. Face AI شروع می‌شود
4. در Tab "Overview" می‌بینید: Face AI → Active
```

### مثال 2: توقف موقت Timer

```
1. Timer در حال اجراست
2. کلیک: Pause
3. Timer متوقف می‌شود (موقت)
4. کلیک: Resume → ادامه می‌یابد
```

### مثال 3: شروع AI Timing بدون Voice Detection

```
1. در بخش "AI Timing":
   - Voice Detection را غیرفعال کنید (checkbox را خالی کنید)
   - Camera ها را انتخاب کنید
   - کلیک: Start
2. AI Timing فقط با دوربین کار می‌کند (بدون میکروفون)
```

### مثال 4: شروع همه ماژول‌ها به صورت جداگانه

```
1. Timer → Start
2. Face AI → Start (با تنظیمات)
3. AI Timing → Start (با تنظیمات)
4. Content Automation → Start
5. Display → Refresh
6. Media → Start

→ همه ماژول‌ها فعال می‌شوند
```

## 📝 نکات مهم

### 1. وضعیت زنده
- وضعیت هر ماژول هر ثانیه به‌روزرسانی می‌شود
- در Tab "Control" می‌بینید: Active/Inactive
- در Tab "Overview" جزئیات بیشتری می‌بینید

### 2. تنظیمات
- تنظیمات (مثل FPS، Voice Detection) فقط قبل از Start اعمال می‌شوند
- بعد از Start، باید Stop کنید و دوباره Start کنید

### 3. وابستگی‌ها
- بعضی ماژول‌ها به ماژول‌های دیگر وابسته‌اند
- مثلاً AI Timing نیاز به Face AI دارد
- اما می‌توانید Face AI را جداگانه شروع کنید

### 4. Device Selection
- قبل از Start، Camera و Microphone را انتخاب کنید
- در بخش "Device Configuration" در بالای Tab

## 🚨 Troubleshooting

### مشکل 1: ماژول Start نمی‌شود

**بررسی:**
1. در Tab "Overview" وضعیت را چک کنید
2. Event Log را بررسی کنید
3. Device ها را چک کنید (Camera/Microphone)

### مشکل 2: وضعیت به‌روز نمی‌شود

**راه‌حل:**
- Dashboard را refresh کنید
- یا دوباره باز کنید

### مشکل 3: تنظیمات اعمال نمی‌شوند

**راه‌حل:**
- ابتدا Stop کنید
- تنظیمات را تغییر دهید
- دوباره Start کنید
