# 📡 راهنمای استفاده از Hall و Skyroom

## 🎯 تفاوت Hall و Skyroom

### 1. Hall (سالن محلی)
- **تعریف**: سالن فیزیکی که حضار در آن حضور دارند
- **محتوا**: روی پروژکتور، نمایشگر یا تلویزیون سالن نمایش داده می‌شود
- **استفاده**: برای شرکت‌کنندگان حضوری

### 2. Skyroom (پلتفرم آنلاین)
- **تعریف**: پلتفرم وبینار آنلاین برای شرکت‌کنندگان از راه دور
- **محتوا**: از طریق API Skyroom برای کاربران آنلاین ارسال می‌شود
- **استفاده**: برای شرکت‌کنندگان مجازی

### 3. Hall+Skyroom (ترکیبی - Hybrid)
- **تعریف**: همایش ترکیبی (حضوری + مجازی)
- **محتوا**: همزمان در سالن و آنلاین پخش می‌شود
- **استفاده**: برای هر دو گروه شرکت‌کنندگان

## 🎬 سناریوهای کاربردی

### سناریو 1: همایش فقط حضوری
**وضعیت**: همه شرکت‌کنندگان در سالن حضور دارند

**انتخاب**: `hall`

**مثال**:
```
محتوا: کلیپ افتتاحیه.mp4
Platform: hall
Priority: high

نتیجه: کلیپ روی پروژکتور سالن پخش می‌شود
```

### سناریو 2: وبینار فقط آنلاین
**وضعیت**: همه شرکت‌کنندگان از راه دور هستند

**انتخاب**: `skyroom`

**مثال**:
```
محتوا: ارائه PowerPoint.pdf
Platform: skyroom
Priority: normal

نتیجه: PDF در Skyroom برای شرکت‌کنندگان آنلاین نمایش داده می‌شود
```

### سناریو 3: همایش ترکیبی (Hybrid)
**وضعیت**: بخشی از شرکت‌کنندگان حضوری، بخشی آنلاین

**انتخاب**: `hall+skyroom`

**مثال**:
```
محتوا: ویدیو سخنرانی.mp4
Platform: hall+skyroom
Priority: high

نتیجه: 
- ویدیو در سالن روی پروژکتور پخش می‌شود
- همزمان در Skyroom برای شرکت‌کنندگان آنلاین پخش می‌شود
```

## 🔧 نحوه استفاده در Content Automation

### گام 1: باز کردن Content Automation
```
Tools → Content Automation
```

### گام 2: افزودن محتوا
```
1. کلیک: Add Content
2. انتخاب فایل (ویدیو، عکس، PDF)
3. محتوا به Library اضافه می‌شود
```

### گام 3: انتخاب Platform

#### حالت 1: Hall (فقط سالن)
```
1. از لیست Quick Schedule محتوا را انتخاب کنید
2. Platform: hall
3. Priority: high/normal/emergency
4. Schedule Time را تنظیم کنید
5. کلیک: Schedule at Selected Time
```

**نتیجه**: 
- محتوا فقط در سالن پخش می‌شود
- شرکت‌کنندگان آنلاین نمی‌بینند

#### حالت 2: Skyroom (فقط آنلاین)
```
1. محتوا را انتخاب کنید
2. Platform: skyroom
3. Priority: high/normal/emergency
4. Schedule Time را تنظیم کنید
5. کلیک: Schedule at Selected Time
```

**نتیجه**:
- محتوا فقط در Skyroom پخش می‌شود
- شرکت‌کنندگان حضوری نمی‌بینند

#### حالت 3: Hall+Skyroom (ترکیبی)
```
1. محتوا را انتخاب کنید
2. Platform: hall+skyroom
3. Priority: high/normal/emergency
4. Schedule Time را تنظیم کنید
5. کلیک: Schedule at Selected Time
```

**نتیجه**:
- محتوا همزمان در سالن و Skyroom پخش می‌شود
- همگام‌سازی خودکار
- همه شرکت‌کنندگان (حضوری + آنلاین) می‌بینند

## 🔄 همگام‌سازی (Synchronization)

### چگونه کار می‌کند؟

وقتی `hall+skyroom` را انتخاب می‌کنید:

```
1. Schedule Engine زمان را trigger می‌کند
2. Sync Coordinator شروع به کار می‌کند
3. محتوا همزمان به هر دو پلتفرم ارسال می‌شود:
   
   ┌─────────────────────┐
   │  Content Schedule   │
   └──────────┬──────────┘
              │
      ┌───────┴────────┐
      │                │
      ▼                ▼
   [Hall]         [Skyroom]
 (سالن محلی)    (پلتفرم آنلاین)
```

### دقت همگام‌سازی:
- **تاخیر**: کمتر از 500ms
- **بازیابی خودکار**: اگر یکی از پلتفرم‌ها قطع شود
- **Event Log**: تمام اتفاقات ثبت می‌شود

## ⚙️ پیکربندی Skyroom

### پیش‌نیازها:

1. **اکانت Skyroom**
   - آدرس API: `https://your-skyroom.ir/api/`
   - API Key

2. **تنظیمات**
   ```python
   # در config.json یا تنظیمات برنامه
   skyroom_config = {
       "api_url": "https://your-skyroom.ir/api/",
       "api_key": "YOUR_API_KEY",
       "room_id": "12345"
   }
   ```

3. **فعال‌سازی**
   - Skyroom Adapter باید به درستی پیکربندی شود
   - اتصال به API Skyroom تست شود

## 🚀 Best Practices (بهترین روش‌ها)

### 1. انتخاب Platform بر اساس نوع محتوا

| نوع محتوا | Platform پیشنهادی | دلیل |
|-----------|-------------------|------|
| کلیپ افتتاحیه | `hall+skyroom` | همه باید ببینند |
| اسلاید ارائه | `hall` | فقط حضوری نیاز دارند |
| ویدیو آموزشی | `skyroom` یا `hall+skyroom` | بستگی به مخاطب |
| لوگو یا بنر | `hall+skyroom` | برای برندینگ |

### 2. Priority (اولویت)

| Priority | کاربرد | مثال |
|----------|--------|-------|
| `emergency` | محتوای فوری | اعلان اضطراری، اطلاعیه مهم |
| `high` | محتوای مهم | کلیپ افتتاحیه، ویدیو اصلی |
| `normal` | محتوای معمولی | اسلایدها، تصاویر |

### 3. زمان‌بندی دقیق

```
✅ DO: زمان دقیق تنظیم کنید
   Time: 2025-11-04 09:00:00
   Platform: hall+skyroom

❌ DON'T: زمان گذشته بدون بررسی
   Time: 2025-11-03 10:00:00 (دیروز!)
```

## 🔍 Troubleshooting

### مشکل 1: محتوا در Hall پخش نمی‌شود

**بررسی**:
1. Media Player کار می‌کند؟
   - Tools → Media Module
   - یک فایل را load و play کنید

2. Display Controller فعال است؟
   - Tools → Display Manager
   - نمایشگرها را بررسی کنید

3. Local Hall Adapter متصل است؟
   - Event Log را چک کنید
   - به دنبال "LocalHallAdapter connected" بگردید

### مشکل 2: محتوا در Skyroom پخش نمی‌شود

**بررسی**:
1. Skyroom API کار می‌کند؟
   - تنظیمات API را چک کنید
   - API Key صحیح است؟

2. Skyroom Adapter متصل است؟
   - Event Log را چک کنید
   - به دنبال "SkyroomAdapter connected" بگردید

3. اتصال به اینترنت برقرار است؟

### مشکل 3: همگام‌سازی کار نمی‌کند

**بررسی**:
1. Sync Coordinator فعال است؟
2. Event Log را بررسی کنید:
   ```
   Sync started for schedule: xxx
   Sync successful: hall + skyroom
   ```
