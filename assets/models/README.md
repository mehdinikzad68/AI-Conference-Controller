# Dlib Face Landmarks Model

This directory is intended to store the pre-trained Dlib 68-point facial landmark predictor:
`shape_predictor_68_face_landmarks.dat`

### Download Instructions:
1. Download the compressed model file:
   - Official Link: [http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2](http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2)
2. Extract the archive (`.bz2`) using 7-Zip, WinRAR, or command line:
   ```bash
   # Windows (PowerShell/Python/7-Zip) or Linux/macOS:
   bzip2 -d shape_predictor_68_face_landmarks.dat.bz2
   ```
3. Place `shape_predictor_68_face_landmarks.dat` into this directory:
   `assets/models/shape_predictor_68_face_landmarks.dat`
